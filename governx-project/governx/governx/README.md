# GovernX: Automated NIST CSF 2.0 Compliance Engine

An enterprise-grade Governance, Risk, and Compliance (GRC) platform that continuously ingests cloud infrastructure telemetry, maps technical misconfigurations directly to NIST CSF 2.0 subcategories, and generates executive board-ready PDF compliance reports.

## Key Features
- **Continuous Telemetry Scanner:** Audits mock cloud assets for encryption status, public access blocks, and identity policies.
- **NIST CSF 2.0 Framework Matrix:** Maps technical vulnerabilities to NIST subcategories (e.g., `PR.DS-01`, `PR.AA-03`).
- **Executive React Dashboard:** Real-time visualization of active security findings, maturity tiers, and severity levels.
- **ReportLab PDF Engine:** Dynamic generation of downloadable PDF compliance reports directly from live database state.

## Tech Stack
- **Backend:** Python, Django REST Framework, SQLite3, ReportLab
- **Frontend:** React, Vite, CSS Modules / Tailwind
